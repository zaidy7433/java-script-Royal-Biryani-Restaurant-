# 🍛 Royal Biryani Restaurant

Welcome to **Royal Biryani Restaurant**, a JavaScript-based restaurant ordering system. This project allows customers to select food items, enter quantities, calculate bills, and view their order details.

## 🌐 Live Demo
[Visit Royal Biryani Restaurant](https://zaidy7433.github.io/java-script-Royal-Biryani-Restaurant-/)

## ✨ Features

- 🍽️ Food menu selection
- 🔢 Quantity selection
- 💰 Automatic price calculation
- 🏷️ Discount calculation
- 🛵 Different order types
- ➕ Extra charges calculation
- 🧾 Final bill generation
- 📋 Multiple order management
- 📦 Order storage using JavaScript arrays and objects

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📚 JavaScript Concepts Used

- Variables
- Arrays
- Objects
- Conditional Statements
- If-Else
- Loops
- Functions
- Array Push Method
- String Methods
- JSON.stringify()
- Mathematical Operations

## 🚀 How to Use

1. Open the website.
2. Select your desired food item.
3. Enter the quantity.
4. Choose your order type.
5. View the calculated subtotal.
6. Apply discounts and extra charges.
7. Generate your final bill.
